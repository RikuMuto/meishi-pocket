名刺ポケット（iPhone用・オフラインPWA）

【重要】このZIPファイルをiPhoneの「ファイル」からタップするだけでは動きません。
iPhoneのみでインストールするには、最初の1回だけHTTPSのWebサイトに4ファイルを置き、Safariで開いて「ホーム画面に追加」する必要があります。インストール後、通信を切って使えます。

【iPhoneだけで設置する例：GitHub Pages】
1. iPhoneのSafariでgithub.comを開き、無料アカウントにサインイン（なければ作成）。
2. 新しいPublic repositoryを作成（例 meishi-pocket）。公開されるのはアプリのコードのみ。名刺データは公開されません。
3. このZIPを「ファイル」アプリで展開し、index.html / sw.js / manifest.webmanifest / icon.png の4ファイルをリポジトリのルートにアップロード。
4. リポジトリのSettings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
5. 表示された https://ユーザー名.github.io/meishi-pocket/ をSafariで開く。
6. Safariの共有ボタン →「ホーム画面に追加」→「追加」。
7. ホーム画面の「名刺ポケット」アプリを1度開き、オフライン用ファイルを準備。
8. 機内モードで再度開き、オフライン起動を確認。

【機能】
・カメラ/写真ライブラリから名刺表裏を登録
・氏名/会社/役職/連絡先/メモ/タグ/交換日の編集・検索
・画像を縮小してIndexedDBに保存
・JSONバックアップの書き出し/取り込み
・外部API/広告/アクセス解析/ログイン無し

【制約・注意】
・iOS Safari上のPWAではApple標準OCR（Vision）を自動実行できません。写真アプリの「テキスト認識表示」からコピーして入力できます。
・GitHub Pagesを使う場合、コード4ファイルは公開されますが、名刺情報/画像はGitHubにアップロードされません。名刺をアプリに登録する時に外部送信しません。
・OSやSafariによるサイトデータの削除、端末故障、アプリ削除でデータは消える場合があります。バックアップJSONを定期的に「このiPhone内」に保存してください。
・iCloudバックアップが有効な場合にOSによってクラウド同期・バックアップの対象となる可能性があります。必要に応じてiCloudの設定を確認してください。
・外部Webサイトリンクをタップした場合はそのサイトへの通信が発生します。厳密な無通信運用では機内モードをご利用ください。
・Public GitHub Pagesが不要な場合はHTTPS静的ホストを別途使用できます。ただし最初の配信は必要です。
